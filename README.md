# Quiz-Platform-Programming-Club-
Quizzr is a platform where student can practise jee style questions with both level jee mains and advanced.
🛠️ Tech Stack used:
HTML5 – Website structure
CSS3 – Styling and responsive design
JavaScript – Quiz logic, DOM manipulation.
Features include:
A login portal for email
Multiple quizzes (JEE Mains and JEE Advanced)
Interactive multiple-choice questions
Next and Previous question navigation
Saves selected answers while navigating
Score and percentage calculation
An alert if questions are unanswered
