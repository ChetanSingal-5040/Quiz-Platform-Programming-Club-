# Quiz-Platform-Programming-Club-<br>
Quizzr is a platform where student can practise jee style questions with both level jee mains and advanced.<br>
🛠️ Tech Stack used:<br>
HTML5 – Website structure<br>
CSS3 – Styling and responsive design<br>
JavaScript – Quiz logic, DOM manipulation.<br>
Features include:<br>
A login portal for email<br>
Multiple quizzes (JEE Mains and JEE Advanced)<br>
Interactive multiple-choice questions<br>
Next and Previous question navigation<br>
Saves selected answers while navigating<br>
Score and percentage calculation<br>
An alert if questions are unanswered<br>
